# Liquidation Heatmap

## Definition
A visual map showing where leveraged positions will be forcibly closed (liquidated) at various price levels.

## Reading It
- Bright clusters above price = longs to be liquidated if price drops there
- Bright clusters below price = shorts to be liquidated if price rises there
- Price is often "drawn" toward dense liquidation clusters

## Key Signals
- Large cluster nearby = likely target for next move
- Price sweeps a cluster then reverses = liquidity grab complete
