This vault is a crypto market analysis system built in Obsidian.

All core rules, logic, language standards, and output formats are in: [[CORE_RULES]]

## Vault Structure

| Folder | Contents |
|--------|---------|
| `prompts/` | AI instruction files — how to think and respond |
| `templates/` | Blank forms for setups, patterns, reviews |
| `setups/` | Real market cases — one file per setup |
| `patterns/` | Repeated market behaviors confirmed across setups |
| `concepts/` | Definitions of key market terms |
| `reviews/` | Weekly review files |
| `lessons.md` | All lessons learned, aggregated |
| `index.md` | Full vault map, grouped by type and tag |

## Key Reminders

- Always read `CORE_RULES.md` before any analysis
- Always check `index.md` for relevant historical files before concluding
- Outcome-validated setups are more reliable than structural-only comparisons
- If outcomes are missing, say so clearly
- Do not invent missing data
